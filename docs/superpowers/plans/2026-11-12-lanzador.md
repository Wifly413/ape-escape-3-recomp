# Lanzador de Ape Escape 3 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Abrir el recomp nativo de Ape Escape 3 con un ejecutable propio, `ApeEscape3.exe`, con icono y sin ventana de consola.

**Architecture:** Programa Win32 de un solo hilo, subsistema GUI, sin dependencias fuera de la API de Windows. `config.ini` define la ruta del ISO y las carpetas; el lanzador valida, arranca `runtime\ps2run.exe` con el directorio de trabajo correcto y termina. La lógica pura (leer configuración, construir argumentos, validar) vive separada del código de arranque para poder probarla sin abrir ventanas.

**Tech Stack:** C++20, Win32, llvm-mingw portable (clang 23 + `windres`), PowerShell solo para generar el `.ico`, PowerShell `Make-`/`clang++` desde `build.cmd`.

**Spec:** `docs/superpowers/specs/2026-11-12-lanzador-design.md`

## Global Constraints

- Solo Windows x86-64. Sin dependencias externas: Win32 y la biblioteca estándar.
- Compilador: `E:\Recomps\ps2-native-recomp\tools\portable\llvm-mingw\bin\clang++.exe`.
- El ejecutable es de subsistema GUI (`-mwindows`): nunca abre consola.
- Rutas internas en UTF-8 (`std::string`); se convierten a `wchar_t` solo al llamar a Win32.
- Todo mensaje al usuario, en español.
- El repositorio no contiene nunca `runtime/`, `game/`, `*.iso`, ni el `.exe` compilado.
- El icono es arte propio; no se usa la carátula ni el logo de Sony.
- Commits en español con conventional commits (`feat:`, `fix:`, `chore:`).
- Los tests son un ejecutable sin framework: `build.cmd test` devuelve 0 si todo pasa.

## Review Focus

- **Ruta del ISO con espacios, comas y paréntesis** (`D:\games\Ape Escape 3 (Europe) (En,Fr,De,Es,Fi).iso`): la línea de comandos que recibe `ps2run` debe reconstruir exactamente ese argumento.
- **Rutas con acentos o `ñ`**: la carpeta del proyecto puede acabar en `D:\Proyectos Programación`; nada puede depender de la página de códigos ANSI.
- **`config.ini` guardado por Notepad**: BOM UTF-8, CRLF y líneas en blanco no deben romper el análisis.
- **Runtime ausente o renombrado**: debe salir un mensaje claro, no un cierre silencioso.
- **Carpeta movida de sitio**: nada puede depender de `E:\Recomps` codificado a mano; todo se resuelve desde la ubicación del `.exe`.
